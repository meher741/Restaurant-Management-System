# Advanced Restaurant Management System

A production-style restaurant management system built using Django,
Django REST Framework and PostgreSQL.

## Technology Stack

- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication
- React.js
- REST API
- Swagger/OpenAPI

## Main Modules

- Authentication
- Restaurant Management
- Menu Management
- Table Management
- Reservations
- Orders
- Kitchen Management
- Inventory
- Payments
- Reports
- Admin Dashboard
